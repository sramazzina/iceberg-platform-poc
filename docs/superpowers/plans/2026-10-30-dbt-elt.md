# Iceberg catalog lab — ELT with dbt and a Spark Thrift Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal ELT pipeline: a PySpark job loads locally generated TPC-H Parquet files into Iceberg (`tpch_raw`), and one generic dbt project transforms them (`tpch_staging`, `tpch_marts`) on any catalog of the lab, through a new Spark Thrift Server that external JDBC clients (DBeaver) can also use.

**Architecture:** A new Compose service `spark-thrift` (profile `thrift`) runs the Spark Thrift Server from the `spark` image, with the same catalog configuration. dbt (`dbt-spark`, method `thrift`) runs in the `spark` container and connects to `spark-thrift:10000`; each dbt target selects its catalog with `spark.sql.defaultCatalog` in the session configuration. DuckDB generates the TPC-H files in `./landing`; PySpark scripts in `./elt` load and clean the raw tables. Make targets wrap every step.

**Tech Stack:** Spark 4.1.3 Thrift Server (HiveServer2 protocol), dbt-core 1.12.6, dbt-spark 1.11.0 (PyHive 0.7.0, thrift 0.22.0), DuckDB 1.5.6 (`tpch` extension), PySpark, Bash, Docker Compose, GNU Make.

**Spec:** `docs/superpowers/specs/2026-10-30-dbt-elt-design.md`.

```python
"""Generates the TPC-H tables as Parquet files with DuckDB (spec 2026-10-30-dbt-elt,
section 6.3). Usage: python3 tpch_gen.py SF OUTDIR. Does nothing when OUTDIR is complete."""
import pathlib
import sys

import duckdb

TABLES = ["region", "nation", "customer", "supplier", "part", "partsupp", "orders", "lineitem"]


def main():
    if len(sys.argv) != 3:
        sys.exit("usage: tpch_gen.py SF OUTDIR")
    sf, out = sys.argv[1], pathlib.Path(sys.argv[2])
    try:
        scale = float(sf)
    except ValueError:
        sys.exit(f"tpch-gen: SF must be a number (got '{sf}')")
    if scale <= 0:
        sys.exit(f"tpch-gen: SF must be greater than 0 (got '{sf}')")
    if all((out / f"{t}.parquet").exists() for t in TABLES):
        print(f"tpch-gen: {out} is complete, nothing to do")
        return
    out.mkdir(parents=True, exist_ok=True)
    con = duckdb.connect()
    con.execute("SET autoinstall_known_extensions = false")
    con.execute(f"CALL dbgen(sf = {scale})")
    for t in TABLES:
        # Write to a temporary name first: a complete file always has its final name.
        tmp = out / f".{t}.parquet.tmp"
        con.execute(f"COPY {t} TO '{tmp}' (FORMAT parquet)")
        tmp.rename(out / f"{t}.parquet")
        print(f"tpch-gen: {out / t}.parquet")


if __name__ == "__main__":
    main()
```

```python
"""Loads the TPC-H Parquet files into CATALOG.tpch_raw (spec 2026-10-30-dbt-elt,
section 6.4). Usage: spark-submit tpch_load.py CATALOG SF [UNTIL]
With UNTIL (YYYY-MM-DD), orders keeps the rows with o_orderdate <= UNTIL and lineitem keeps
the rows of those orders. Every table is replaced (CREATE OR REPLACE)."""
import datetime
import pathlib
import sys

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, lit

from tpch_gen import TABLES

CATALOGS = ("polaris", "nessie", "rest")


def main():
    if len(sys.argv) not in (3, 4):
        sys.exit("usage: tpch_load.py CATALOG SF [UNTIL]")
    catalog, sf = sys.argv[1], sys.argv[2]
    until = sys.argv[3] if len(sys.argv) == 4 and sys.argv[3] else None
    if catalog not in CATALOGS:
        sys.exit(f"tpch-load: CATALOG must be one of {', '.join(CATALOGS)} (got '{catalog}')")
    if until:
        try:
            datetime.date.fromisoformat(until)
        except ValueError:
            sys.exit(f"tpch-load: UNTIL must be a date YYYY-MM-DD (got '{until}')")
    src = pathlib.Path("/workspace/landing/tpch") / f"sf{sf}"
    if not all((src / f"{t}.parquet").exists() for t in TABLES):
        sys.exit(f"tpch-load: no complete data in landing/tpch/sf{sf}: run make tpch-gen SF={sf} first")

    spark = SparkSession.builder.appName("tpch-load").getOrCreate()
    spark.sql(f"CREATE NAMESPACE IF NOT EXISTS {catalog}.tpch_raw")
    orders = spark.read.parquet(str(src / "orders.parquet"))
    if until:
        orders = orders.where(col("o_orderdate") <= lit(until).cast("date"))
    for t in TABLES:
        if t == "orders":
            df = orders
        else:
            df = spark.read.parquet(str(src / f"{t}.parquet"))
        if t == "lineitem" and until:
            df = df.join(orders.select("o_orderkey"), df.l_orderkey == orders.o_orderkey, "left_semi")
        name = f"{catalog}.tpch_raw.{t}"
        df.writeTo(name).using("iceberg").createOrReplace()
        print(f"tpch-load: {name}: {spark.table(name).count()} rows")
    spark.stop()


if __name__ == "__main__":
    main()
```

```python
"""Drops the namespaces tpch_marts, tpch_staging and tpch_raw of CATALOG with their tables,
views and files (spec 2026-10-30-dbt-elt, section 6.6). Usage: spark-submit tpch_clean.py CATALOG
Drop policy per catalog (tests/catalog-smoke.sh): nessie never deletes files, so the files
are deleted with the AWS CLI; polaris deletes them with PURGE (the VM role can only list
under polaris/); rest deletes them with PURGE, the AWS CLI deletes what is left."""
import os
import subprocess
import sys

from pyspark.errors import AnalysisException
from pyspark.sql import SparkSession

NAMESPACES = ["tpch_marts", "tpch_staging", "tpch_raw"]
PURGE = {"nessie": False, "polaris": True, "rest": True}
OWN_FILES = {"nessie": True, "polaris": False, "rest": True}


def aws(*args):
    return subprocess.run(["aws", "s3", *args], capture_output=True, text=True)


def main():
    if len(sys.argv) != 2 or sys.argv[1] not in PURGE:
        sys.exit("usage: tpch_clean.py polaris|nessie|rest")
    catalog = sys.argv[1]
    root = f"s3://{os.environ['S3_BUCKET']}/{catalog}/"
    spark = SparkSession.builder.appName("tpch-clean").getOrCreate()
    present = {r[0] for r in spark.sql(f"SHOW NAMESPACES IN {catalog}").collect()}
    failed = False
    for ns in NAMESPACES:
        if ns not in present:
            continue
        try:
            views = {r.viewName for r in spark.sql(f"SHOW VIEWS IN {catalog}.{ns}").collect() if not r.isTemporary}
        except AnalysisException:
            views = set()  # The catalog has no Iceberg views (NOTES F7, S4).
        for v in sorted(views):
            spark.sql(f"DROP VIEW IF EXISTS {catalog}.{ns}.{v}")
            print(f"tpch-clean: dropped view {catalog}.{ns}.{v}")
        tables = [r.tableName for r in spark.sql(f"SHOW TABLES IN {catalog}.{ns}").collect()
                  if not r.isTemporary and r.tableName not in views]
        for t in sorted(tables):
            name = f"{catalog}.{ns}.{t}"
            rows = spark.sql(f"DESCRIBE TABLE EXTENDED {name}").where("col_name = 'Location'").collect()
            location = rows[0].data_type.rstrip("/") + "/" if rows else None
            spark.sql(f"DROP TABLE IF EXISTS {name}{' PURGE' if PURGE[catalog] else ''}")
```

````markdown
## ELT with dbt

The lab has a minimal ELT pipeline on TPC-H data:

- **EL:** `make tpch-load` loads Parquet files from `landing/` into the namespace
  `tpch_raw` of a catalog (PySpark).
- **T:** a dbt project (`dbt/`) builds `tpch_staging` (tables) and
  `tpch_marts` (tables) in the same catalog.

The dbt project does not depend on the catalog. The target selects it: `polaris`, `nessie`
or `rest`. dbt runs in the `spark` container and sends SQL to the Spark Thrift Server
(service `spark-thrift`, profile `thrift`).

### Run the pipeline

1. Add `thrift` and the catalog to `COMPOSE_PROFILES` in `.env`, for example
   `COMPOSE_PROFILES=nessie,thrift`.
2. Start the stack:

   ```bash
   make up
   ```

3. Generate the data. `SF` is the TPC-H scale factor: `SF=1` is about 1 GB of raw data,
   6 million rows in `lineitem`. The files go to `landing/tpch/sf1/` (git-ignored).

   ```bash
   make tpch-gen SF=1
   ```

4. Load the orders up to the end of 1996:

   ```bash
   make tpch-load CATALOG=nessie SF=1 UNTIL=1996-12-31
   ```

5. Build the models and run the dbt tests:

   ```bash
   make dbt CATALOG=nessie ARGS=build
   ```

6. Load all the data, then run the models again. The incremental model
   `tpch_marts.fct_lineitem` merges only the line items of the new orders: its last
   snapshot is an `overwrite`. Polaris and `rest` keep the snapshot history. Nessie keeps
   the history in its commit log and shows only the snapshot of the current commit.

   ```bash
   make tpch-load CATALOG=nessie SF=1
   make dbt CATALOG=nessie ARGS=run
   ```

7. Remove the tables of the pipeline. The Parquet files in `landing/` stay; delete the
   directory `landing/tpch/` to remove them.

   ```bash
   make tpch-clean CATALOG=nessie
   ```

For another catalog, use `CATALOG=polaris` or `CATALOG=rest`. `SF=1` is verified; larger
scale factors are not verified (the Thrift Server has `spark.driver.memory 4g`).

### Connect a JDBC client (DBeaver)

The Spark Thrift Server speaks the HiveServer2 protocol. It has **no authentication**; the
port is published on `127.0.0.1` of the VM only.

1. Start the stack with the profile `thrift` (see [Run the pipeline](#run-the-pipeline)).
2. On a remote VM, open the tunnel for port 10000 (see [SSH tunnel](#ssh-tunnel)).
3. In DBeaver, create a connection of type **Apache Hive** (DBeaver downloads the driver).
4. Set the JDBC URL to `jdbc:hive2://localhost:10000/;auth=noSasl`, user `spark`, no
   password.
5. Use three-part names: `SELECT * FROM nessie.tpch_marts.revenue_by_nation`. Each catalog
   that is on is available. To select a default catalog, add it to the URL:
   `jdbc:hive2://localhost:10000/;auth=noSasl?spark.sql.defaultCatalog=nessie`. The
   catalog must have the namespace `default` (`make dbt` creates it).
````
